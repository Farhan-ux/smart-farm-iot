# Smart Farm IoT Dashboard

Agricultural monitoring interface for Greenfield Smart Farm with 8 field zones, soil sensors, and automated irrigation, built with Next.js 14 and Recharts.

## Features

- **8-Zone Field Map** — Color-coded grid showing crop type, growth stage, and health score per zone
- **Soil Sensor Charts** — Switchable line charts for moisture, pH, temperature, NPK across all zones
- **Crop Health Table** — Comprehensive zone status with health percentages and moisture levels
- **Irrigation Queue** — Scheduled and running irrigation events with volume and duration
- **Weather Forecast** — 7-day forecast with current conditions, temperature, humidity, and UV index

## Tech Stack

- Next.js 14 (Pages Router)
- TypeScript
- Tailwind CSS
- Recharts

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
